## 三个藏在套餐详情里的限制

参数表上看不出、却直接影响使用体验的，主要是下面三条。下单前各花一分钟确认，能省掉大部分售后扯皮。

**流量按单向还是双向计费。** DMIT 的东京全系明确写着流量按上下行合计（IN + OUT）计算：标称 1TB，指的是下行加上行一共 1TB。很多商家只计服务器发出的流量，同样的"1TB"实际能用得多。两种计费方式差出一倍，看错了这个数字，预算会直接失真。

**超流量之后是限速还是停机。** DMIT 的政策是超量限速、不停机：T1 系列用到额度后按套餐降到 50–500Mbps 继续跑，下个计费周期恢复。对挂机器人、跑定时任务的用户，这几乎是决定性的差异——不少商家超量直接停机，服务当场中断，还得等充值或等周期。条款里找不到这条说明的，按最坏情况做预期。

**端口速率和流量是绑在一起卖的。** 入门套餐常见“500GB @ 500Mbps”的写法，指月流量 500GB、端口 500Mbps。也有反过来的组合，比如 zgovps 东京 $58/年 那档，端口只有 100Mbps，流量按公平使用给 500GB——带宽小，适合轻量应用，想跑大流量就直接排除这类。反过来，只是挂个博客或监控脚本，小端口的套餐反而更便宜。
